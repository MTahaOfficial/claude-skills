# Claude skills

Skills for Claude by Muhammad Taha.

## demo-video

Makes a 60-90 second product or investor demo video from real code, real API output and measured benchmarks. The video is an HTML page with timed animations, rendered to MP4 with Hyperframes.

It covers:

- choosing the audience (clients or investors)
- collecting real evidence: a running project, a real API request and response, a benchmark through the real API, real code and database rows
- planning scenes and building the HTML composition
- checking and rendering the video
- delivering the files and uploading to Upwork

## Install

Copy the `demo-video` folder into your Claude skills folder, or add `demo-video/SKILL.md` as a skill in Claude.
