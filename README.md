# demo-from-code

A Claude skill that makes a 60-90 second product or investor demo video from real code, real API output and measured benchmarks. Nothing is mocked up: the video shows your project actually running.

The video is an HTML page with timed animations, rendered to MP4 with Hyperframes.

## What it does

- chooses the audience (clients or investors)
- collects real evidence: a running project, a real API request and response, a benchmark through the real API, real code and database rows
- plans the scenes and builds the HTML composition
- checks and renders the video
- delivers the files and uploads to Upwork

## Install

Copy the `demo-from-code` folder into your Claude skills folder, or add `demo-from-code/SKILL.md` as a skill in Claude.
